# KCS - Quản lý chất lượng công trình

Kho này **chỉ chứa file cài đặt** phần mềm KCS (không có mã nguồn).

## Cài đặt

1. Vào mục **[Releases](../../releases/latest)**, tải file **`KCS-Cai-Dat-x.y.z.exe`** (khoảng 1 MB).
2. Bấm đúp để cài. Máy cần có mạng Internet: bộ cài sẽ tự tải phần chính (khoảng 110 MB).
3. Nếu Windows báo "Windows đã bảo vệ PC của bạn": bấm **Thông tin thêm** → **Vẫn chạy**.

Phần mềm tự kiểm tra và cập nhật phiên bản mới. Dữ liệu công trình và bản quyền được giữ nguyên khi cập nhật.

## Liên hệ

Liên hệ: 0918.448.089 để được dùng thử và cấp bản quyền.
